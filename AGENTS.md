# Agent guide

Before making changes, read:

- [Project architecture](docs/architecture.md) for routes, data flow, and key modules.
- [Development and run guide](docs/development.md) for setup, environment, and validation commands.

Keep changes consistent with the existing Next.js App Router, TypeScript, Tailwind CSS, and direct PostgreSQL patterns. Use the existing route handlers, server actions, data helpers, and UI components where applicable. Do not commit environment files or credentials.

When changing routes, data flow, or setup commands, update the relevant guide.
